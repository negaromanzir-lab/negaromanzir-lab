# 🌐 Personal Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and experience as a **Full-Stack Web Developer** and **Computer Science student**. It features an interactive resume, project showcase, smooth animations, and a functional contact form powered by EmailJS.
